# Security Policy

## Reporting a Vulnerability

Please report security issues privately to **net2outlawzz@gmail.com** with the subject `[SECURITY] BrandEx-IP-Practice`.

Include a clear description, steps to reproduce, and potential impact. Do not open public issues for security vulnerabilities.

## Scope notes

- Current data layer is mock data; when a real API is connected, keep credentials server-side.
- Do not commit `.env` files containing secrets.
